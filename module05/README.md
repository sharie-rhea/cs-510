# CPU and Memory Details Script

## Dependencies

First, ensure you have the required dependencies.

- [Python v3.11+](https://www.python.org/downloads/)
- A stable internet connection.
    - This script queries a few webpages to demonstrate limited resource access.

## Running the Script

### Integrated Developer Environment

1. Use the "run button" or other conventional way to run a program in your preferred IDE.
2. Observe the formatted output in your IDE's terminal pane.

### Terminal

1. `python3 semaphore.py`
2. Observe the formatted output in the terminal.

### Note on Execution Time

If desired, change the `total_processes` or `max_concurrent_processes` variables to see the execution time change.
