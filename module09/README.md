# Operating System Statistics Script

## Dependencies

First, ensure you have the required dependencies.

- [Python v3.11+](https://www.python.org/downloads/)
- [psutil](https://pypi.org/project/psutil/): `pip install psutil`
- Any text file in the same directory as `projecttwo.py` titled `projecttwo.txt`.

### Optional `venv`

If desired, create a virtual environment for the `psutil` library:

```bash
python3 -v venv .venv
source .venv/bin/activate
```

To disable the `venv`:

```bash
deactivate
```

## Running the Script

### Integrated Developer Environment

1. Use the "run button" or other conventional way to run a program in your preferred IDE.
2. Observe the formatted output in your IDE's terminal pane.

### Terminal

1. `python3 projecttwo.py`
2. Observe the formatted output in the terminal.

### Note on CPU Utilization

If desired, run an intensive application on your system to see the CPU utilization change. The `stress` utility on Linux is convenient for this.
